## How to contribute

* Create a new branch from the 'master' and move on
* Create a pull request and wait for it to be reviewed (or just merged, who cares? no, definitely reviewed. I promise)

## Issues

* Feel free to open issues for bugs, questions, or suggestions (If you are brave enough)
* Try to provide as much detail as possible

## Code style

* Follow the existing code style in the project
* Consistency is more important than perfection

## Questions

If you're unsure about something, open an issue - happy to help
